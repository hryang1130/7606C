## 5. Insertion：报告中的负结果分析

### 5.1 可用于报告的正文

我们最初选择 PegInsertionSide，以考察视觉 Diffusion Policy 在高精度操作任务中的表现。根据目前的实验反馈，已开展的尝试尚未获得可用于后续研究的成功基线。正式报告将结合各次运行的配置、训练预算及闭环成功数，给出这一负结果的具体适用范围。

这一结果说明，当前测试的实验设置尚未建立可靠的插入策略；它不能证明 RGB Diffusion Policy 无法解决插入任务。现有汇总证据也不足以确定瓶颈来自视觉表征、示范覆盖、动作控制，还是多种因素共同作用。训练能够正常执行、去噪 loss 下降与闭环任务成功是不同层面的观察。

对于利用失败经验改进策略的拓展研究，若基线成功率接近零，失败轨迹可能覆盖策略的大部分行为，成功行为对照也会不足，使负向引导的效果难以解释。因此，我们将 PlaceSphere 纳入替代任务的可行性评估，同时保留 RGB 观测设定和核心研究问题。PegInsertionSide 的探索作为负结果保留；替代任务上的结论不用于支持精密插入能力。

## 10. Failure-aware 引导实验（PlaceSphere，2026-10-04）

在 PlaceSphere（基线 N=100，horizon 200，checkpoints s1–s3）上跑完整 failure-aware 流程。方法、对照和预注册规则见 [failure-aware 方案](failure_aware_finetuning_plan.md)；协议 `configs/failure_aware/protocol.toml`；每一步的选择都写在锁定文件 `configs/failure_aware/placesphere.toml`，**在 test 前 commit**（dp-manip `8085fb9`，sha256 `5041d025…`）。

### 10.1 方法要点

- **不是新的网络组件**：失败模型就是 baseline 的 `DiffusionPolicy`（UNet）副本，视觉编码器冻结，只在失败轨迹上微调噪声预测器。推理时由包装器 `FailureGuidedPolicy` 在每个去噪步合成 `ε = ε_s + λ(ε_s − ε_f)`；baseline checkpoint 不变。
- **数据来自 baseline 自己的闭环 rollout**（不是专家示范）：失败 = 整个回合 `success_once == False`。seed 段与专家示范、val、test 均不重叠（采集 20000+，holdout 21000–21099，调参 22000–22047）。
- **对照**：C1 = 用同一批 rollout 里的**成功**轨迹微调的模型做负向引导（排除"往任意微调副本反方向推就有效"）；C2 = 直接用这个成功模型做策略（自我模仿）。

### 10.2 预注册设计与门控（全部在 test 前锁定）

| 步骤 | 锁定结果 |
| --- | --- |
| select-cell | N=100，正常模式；val 均值 0.372（`val_final_h200.json`），horizon 200 |
| 采集 | 每个 checkpoint K=150 失败 + 150 成功；为凑够 K 分别跑了 488 / 460 / 444 回合（采集成功率 0.307 / 0.326 / 0.338）；holdout 各 100 回合；失败轨迹截到 `L_fail` = 184 步 |
| 微调（pilot） | lr 1e-5，**5000 步**，batch 64。6 个候选的离线 margin 都在 0.053–0.055，差距 < 5%，按规则取步数最少、lr 最低 |
| offline gate | **PASSED**：gap_fail / gap_succ = 0.055 / −0.001（s1）、0.059 / 0.006（s2）、0.042 / 0.002（s3） |
| dry-run | m = 0.00288（两模型噪声预测平均余弦 0.994）；α = 0 逐位复现 baseline ✓ |

### 10.4 判读（按预注册措辞）

- **H1 不成立**：在这个样本量下，失败引导（F）与基线**不可区分**，不能声称失败引导提升了闭环成功率。点估计 +1.7 pp。
- **H2、H3 同样不可区分**：即使有微小提升，也无法归因于"失败"信息（F 与 C1 只差 1.3 pp）；自适应权重相对固定权重也没有可测差异。
- **为什么测不出**：引导几乎没有改变策略行为。F 与 B 在 300 对回合里只有 21 对结果不同（7%），噪声只改动约 3%。方案估算最小可检测效应（约 7–8 pp）时假设约 20% 的回合对结果不同；这里差异远少于此，1–2 pp 的效应本来就超出了检测能力。
- **A 的问题**：失败模型和基线预测几乎同向（m = 0.0029），按方案校准后 adaptive 的 α 高达 173–694，tuning 上 α 越大越差。test 只用了最小的 α（173），结果与 F 相当。
- **代价**：引导需要两次 UNet 前向，推理耗时约翻倍（≈ 1.0 s vs 0.5 s / 次）。
- 这是一个**中性 / 负结果**，按方案 §9 可以如实报告；预注册的门控（gate、α = 0 复现）都通过，说明流程本身是有效的，结论不是实现错误造成的。
